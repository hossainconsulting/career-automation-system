# Career Automation System

## Purpose

A planned personal tool for tracking job applications, tailoring resumes
and automating job searches.

## Current status

Planning only. No application code, integrations, tests or runnable
demonstrations have been implemented. The technology stack is undecided.

## Planned capabilities

- [ ] Track roles, employers, application dates, statuses and follow-ups.
- [ ] Tailor resume drafts to job descriptions using verified experience.
- [ ] Automate searches through supported APIs or permitted data sources.
- [ ] Deduplicate opportunities and retain links to original listings.
- [ ] Provide a review step before using generated application materials.

Resume tailoring must preserve factual accuracy and must not invent
experience, qualifications or achievements.

## Running the project

There is no runnable implementation yet. Setup instructions will be added
with the first working feature.

## Evidence and verification

No implementation evidence is available yet. Completed features will
include reproducible examples, tests, results and known limitations.
Public demonstrations will use synthetic application and resume data.

## Data and credentials

Keep personal resumes, application records, credentials and access tokens
out of this public repository.
